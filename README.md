# GLM-auto-reset

## 有什么用

自动监控 [bigmodel.cn](https://bigmodel.cn/coding-plan/personal/usage) 的 GLM Coding Plan 个人套餐用量:**当 5 小时额度 / 周额度使用达到阈值时,自动调用官网"重置管理"同款接口使用一张重置卡**(优先使用官方标记"优先"的卡),无需人工盯守。自带小型桌面窗口,关闭窗口即程序退出。

## 下载

克隆仓库到本地:`git clone https://github.com/maxi3777/GLM-auto-reset.git`

## 配置

所有配置均可在程序窗口中修改并保存(存于本地 `config.json`),默认值如下:

| 配置 | 默认值 | 说明 |
|---|---|---|
| 触发阈值 | 5小时 99% / 周 99.5% | 已用百分比达到即触发重置(按精确值判断) |
| 最多用卡 | 5小时 3 张 / 周 2 张 | 程序单次运行期间各自硬上限,重启才重置 |
| 检查间隔 | 慢 30 秒 / 快 5 秒 | 任一额度 ≥ 快检阈值(5h 93% / 周 98%)时自动切快检 |
| 演练模式 | 关 | 开启后只记录"将用哪张卡",不真正调用接口 |

## 使用

```bash
pip install -r requirements.txt
python -m playwright install chromium   # 首次安装浏览器内核(约 130MB)
python main.py                          # 或双击 启动.bat
```

首次运行会弹出浏览器窗口,手动登录一次即可——登录态保存在本地 `browser_profile/`,之后无头运行不再打扰。需要登录/安全验证时程序会自动弹窗并在日志中提示。

## 安全机制(防误耗卡)

- 分类预算:5 小时卡、周卡各自限定单次运行最多用量
- 超时/结果未知绝不重发(避免重复消耗),只用只读接口核对实际状态
- 用卡成功后 5 分钟冷却;支持演练模式零消耗验证
- 周额度优先用周卡(一张同时回满周 + 5 小时额度);仅 5 小时超阈值用 5 小时卡,可配置周卡兜底

## 工作原理

通过 Playwright 持久化浏览器打开官网用量页,在页面内以登录态调用官网自身接口(读额度、读卡列表、用卡),与官网"重置管理"按钮同一套接口,不模拟点击、不抓 DOM。同类内选有效期最早的可用卡(即官方 UI 标"优先"的那张)。

## 测试

全部自动化测试跑在本地 mock 服务器上,零接触真实网站:`python -m pytest`(40 项)。
